# Where to get help — you're never stuck alone

The AI team (Niki + Honza) wants you to build, and to ask whenever you're stuck. Options, from quickest to most involved:

## Quick question / tip
**Slack `#ai-insights`** — prompt tips, tool questions, quick "is this possible?" checks. Agency-wide, English.

## A proper conversation — Book an AI session
For a new project idea, an architecture question, when you're stuck, or anything that needs a real discussion:

**🗓️ Book an AI session** (Teamwork → AI Insights):
https://evisions.teamwork.com/app/tasklists/826628/list

Create a task there describing your idea (there's an intake prompt / Gem to help you write it), and the AI team picks it up and books a slot if needed. Attach any sensitive inputs (numbers, client data, credentials) **in Teamwork, not in an AI chat**.

## Regular rhythm
- **AI Champion monthly sync** — 15-min stand-up + a focused topic, once a month.
- **AI Insights Deep Dive** — 4th week of the month, workshop style, mandatory for Champions. Bring "I have this issue, how do we solve it?" problems here.
- **AI Insights for all** — 2nd week of the month, agency-wide.

## Rule of thumb
If you've been stuck for more than a few minutes, or you're about to make an architecture decision you're unsure about, **Book an AI session**. Cheaper than building the wrong thing.
