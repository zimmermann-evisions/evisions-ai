# Tech SEO + accessibility minimum — build-time checklist

> Applied automatically to every site at build time (Claude Code). Not a
> client question — project-specific inputs come from brief section 7b.
> Will be referenced by the web build skill once it exists.

## Tech SEO
- [ ] Unique title + meta description on every page
- [ ] One H1 per page, logical heading hierarchy (H2, H3)
- [ ] OG tags (title, description, share image)
- [ ] Canonical URL
- [ ] Alt text on all content images
- [ ] sitemap.xml and robots.txt
- [ ] noindex on staging until go-live, and on pages listed in brief 7b
- [ ] 301 redirects for old URLs (redesign — list from brief 7b)
- [ ] hreflang if brief 7b lists more than one language
- [ ] Structured data where relevant (Organization, FAQPage)
- [ ] HTTPS, compressed images, no unnecessary scripts

## Accessibility minimum
- [ ] Sufficient text contrast
- [ ] Keyboard navigation + visible focus state
- [ ] Form labels and error messages
- [ ] Clear button/link names (never "click here")
- [ ] Works on mobile
- [ ] Respects the device's "reduce motion" setting
